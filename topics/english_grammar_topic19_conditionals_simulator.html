Conditionals

Learn how to talk about facts, real possibilities, imaginary situations, and unreal past events.

What is a conditional sentence?

A conditional sentence describes a condition and its result. It often uses if.

If it rains, we will stay home.
Condition: if it rains · Result: we will stay home

The if-clause gives the condition. The main clause gives the result. The clauses can change order:

If you hurry, you will catch the bus.
You will catch the bus if you hurry.

When the if-clause comes first, we normally use a comma. When it comes second, a comma is usually unnecessary.

Zero conditional — facts and routines

Form: If + simple present, simple present.

If you heat ice, it melts.
If I drink coffee late, I sleep badly.
Plants grow if they get enough light.

Use it for general truths, rules, and things that regularly happen. When can sometimes replace if when the result is expected or routine.

Try it

If water reaches 100°C at sea level, it ___.

First conditional — real future possibility

Form: If + simple present, will + base verb.

If I study tonight, I will feel prepared tomorrow.
If it rains, we will cancel the match.
You can take the bus if you leave now.

Use it for a possible future condition and its likely result. In the standard first conditional, don't normally put will directly in the if-clause.

Common mistake: If it will rain, we will stay inside.
Correct: If it rains, we will stay inside.

Try it

If she ___ early, she will catch the train.

Second conditional — imaginary or unlikely present/future

Form: If + simple past, would + base verb.

If I had more free time, I would learn Japanese.
If she lived closer, she would visit more often.
If I were you, I would apologise.

The simple past here usually expresses distance from reality, not past time. In formal or careful English, were is common with all subjects in “If I were you…”

Compare: If I have time, I will help. (real possibility) / If I had time, I would help. (imagined or less likely)

Try it

If I ___ a million dollars, I would travel the world.

Third conditional — unreal past situations

Form: If + past perfect, would have + past participle (V3).

If I had studied, I would have passed the exam.
If they had left earlier, they would have caught the train.

Use it to imagine a different past result. The actual situation is usually the opposite: I didn't study, so I didn't pass.

Mixed conditionals

Mixed conditionals connect different times, often an unreal past condition with a present result.

If I had gone to bed earlier, I wouldn't be so tired now.
Past condition → present result
If she were more organised, she wouldn't have missed yesterday's deadline.
Present/general condition → past result

These forms are more advanced. Learn the four main patterns first, then practise mixed conditionals.
